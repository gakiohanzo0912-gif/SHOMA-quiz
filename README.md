# 翔馬クイズ

翔馬の誕生日用クイズ。全10問(9問 + 鼻毛の最終問題)。スマホのブラウザで遊べます。

- 10問正解 … ジャパニーズウイスキー
- 7問正解 … 雪子奢り
- 5問正解 … 手作り塩辛

## 問題を変えるとき
`index.html` の上のほうにある `var Q = [...]`(1〜9問)と `var FINAL = {...}`(最終問題)を書き換えます。
- `opts` が選択肢、`ans` が正解の番号(0はじまり)
- 最終問題の正解は `correct`(0=出てる 1=出てない 2=鼻水 3=鼻くそ。いまは3)
- モザイクをかける場所は `nose`、景品は `PRIZES`
